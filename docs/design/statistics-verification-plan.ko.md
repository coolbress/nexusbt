# 연구 통계의 검증 계획(오탐률과 검정력)

> 원문: [statistics-verification-plan.md](statistics-verification-plan.md)(영문이 정본). 요약: 엔진의 DSR·PBO·BHY·PSR·MinTRL이 "없는 것을 얼마나 자주 찾는가"를 말한다고 믿기 전에, 답을 아는 자료 생성 과정(DGP)에서 돌려 본다. 이 파일은 그 DGP, 시나리오, 오류 기준, 반복 수를 정한다. 계획일 뿐이며 NexusBT나 시장에 대한 결과가 아니다.

2026-11-04 설계 세션 B 작성(검수 항목 D12). 관련 스펙 절: 5.7, 5.8, 6.2, 6.3, 6.3a, 8.3(P-STAT).

## 1. 두 종류의 합성 자료

| | 회계 fixture | 연구 DGP(이 파일) |
|---|---|---|
| 목적 | 엔진이 체결·현금·기업 행위·라벨을 정확히 계산한다 | 통계 절차가 밝힌 조건 아래에서 주장하는 오류율을 가진다 |
| 출처 | 합성 TDS 생성기(스펙 4.8)와 골든 사례(8.2) | 귀무 또는 효과를 아는 수익·점수 과정 |
| 기대값 | 세션마다 적은 숫자 | Monte Carlo 구간을 붙인 비율 |
| 통과의 뜻 | 산수가 맞다 | 이 DGP와 이 선택 절차에서 비율이 구간 안에 있다 |

엔진이 생기면 연구 DGP를 4.8 생성기로 흘려 넣을 수 있지만(아래 B 단계), 연구 시나리오 통과는 회계에 대해, 골든 사례 통과는 오류율에 대해 아무것도 말하지 않는다.

## 2. 돌리기 전에 정하는 것

시나리오마다 실행 전에 적는다.

1. **귀무가설**과, 검정력을 위한 **대립가설**(효과 크기, 예: 후보 하나의 연율 Sharpe 0.5 또는 1.0).
2. **선택 절차**: 후보 수, 어떤 자료에서 어떻게 고르는지, 무엇을 보고하는지.
3. **오류 기준**: 보고한 주장의 오탐률, 가족별 오류, 거짓 발견 비율 가운데 무엇인지와 명목 수준.
4. **반복 수와 Monte Carlo 오차**: R번 반복에서 비율 p의 표준오차는 √(p(1 − p)/R)이고, R = 10,000이면 p = 5 %에서 약 0.22%p다. 모든 비율에 Wilson 95 % 구간, seed, 라이브러리 버전을 붙인다.
5. **이 시나리오가 보여 주지 못하는 것**: DGP의 한계를 결과 옆에 적는다.

DSR·PBO에 시나리오 공통의 5 % 문턱을 붙이지 않는다. 시나리오마다 자기 기준을 밝힌다.

## 3. 자료 생성 과정

일간 수익 T = 252 × 연수, 후보 수 K ∈ {1, 10, 100, 1,000}.

| id | 과정 | 이유 |
|---|---|---|
| N0 | IID 정규, 평균 0 | 모든 식이 가정하는 기준 |
| N1 | IID Student t(ν = 4)와 비대칭 변형, 평균 0 | PSR이 왜도·첨도를 쓴다 |
| N2 | AR(1), φ = 0.2 | Lo 줄이 볼 수 있는 시계열 의존성 |
| N3 | φ1 = 0, φ2 = 0.3인 AR(2)(ρ1 = 0, ρ2 = 0.3) | `ρ1` 조건이 놓치는 의존성 |
| N4 | 겹치는 보유: IID 5일 합(MA(4)) | 5.8의 라벨 겹침 |
| N5 | 변동성이 두 국면을 오가는 과정, 평균 0 | 비정상성 |
| N6 | α = 0.1, β = 0.85인 GARCH(1,1), 평균 0: 수익은 시계열 무상관, 제곱 수익은 의존 | 수익 의존성 없는 변동성 변화 |
| C1 | 공통 요인 하나를 가진 후보 K개, 쌍별 상관 ρ ∈ {0, 0.5, 0.9}; 그리고 완전한 중복 | 집단의 N과 실질적으로 더 적은 시행 |
| A1 | N0~N5 위에 참 평균(연율 Sharpe 0.5, 1.0)을 가진 후보 하나 | 검정력 |

패널 행은 독립 증거가 아니다. 날짜마다 종목이 많은 시나리오는 행이 아니라 날짜(와 상관된 종목의 군집)를 센다.

## 4. 시나리오

| id | 시나리오 | 비교 | 귀무에서 기대 |
|---|---|---|---|
| S1 | 연구 자료에서 고른 후보 하나를 독립 최종 자료에서 한 번 시험 | 최종 시험의 기각률 | K가 얼마였든 명목 수준(연구 자료의 탐색은 N에 들어가지 않음) |
| S2 | 사전 선언한 K개 후보를 같은 최종 자료에서 평가하고 최고를 보고 | 무보정, DSR(N = K), K에 대한 BHY | 무보정은 K와 함께 커짐; DSR·BHY는 N0에서 명목 기준 근처, C1과 N2~N5에서는 측정 |
| S3 | 최종 결과를 보고 후보를 바꿔 같은 최종 자료를 다시 사용 | 마지막으로 보고한 시험의 기각률 | 부풀려짐; 진단으로 보이는 누적 N은 명목 수준을 되돌리지 못하며, 보고서는 자료를 재사용했다고 말해야 함 |
| S4 | 전체 자료에서 피처 선택·전처리를 하고 검증 분할; 같은 단계를 학습 fold 안에서 | 순수 잡음 피처에서 추정한 OOS 성과 | 전역 방식은 낙관적, fold 안 방식은 그렇지 않음 |
| S5 | 고정 후보 하나를 정한 종료일에 한 번 판정; 21일마다 보고 처음 유의하면 멈춤 | 오탐률 | 고정 종료일은 수준을 지킴; 처음 유의할 때 멈추면 지키지 못함 |
| S6 | 지표 k개(Sharpe, IC, Sortino, …)를 계산해 가장 좋은 것을 보고 | 오탐률 | k와 함께 부풀려짐 |
| S7 | 실패한 후보·기간(수익 없음, 큰 낙폭)을 통계 전에 제거 | 오탐률과 보고한 coverage | 부풀려지며, coverage 줄이 제거를 보여야 함 |
| S8 | 후보 하나에 대해 N1~N5에서 PSR(0)·MinTRL | 기각률 | 측정; N2~N4에서 IID 가정의 비용을 보는 것이 목적 |
| S9 | N0에서 잡음 후보 K개의 PBO; A1 후보 하나를 넣은 경우 | PBO 분포 | 귀무에서 0.5 근처(IS 승자의 OOS 순위가 균등); 진짜 후보가 있으면 낮아짐 |
| S10 | 허용 학습 범위 안에서 행 2 % 부분 표본으로 튜닝 대 전체 행으로 튜닝 | 파라미터 순위 일치, 꼬리 지표, 희귀 사건 coverage | 측정; 부분 표본이 순위·꼬리를 보존한다는 주장은 하지 않음 |
| S11 | 수익 시계열 하나에 스펙 5.7의 "dependence visible" 규칙(시차 1~10 Ljung–Box Q, p < 0.05), T = 252와 252 × 5 | N0·N6에서 표시가 나오는 빈도, N2·N3를 잡는 빈도 | N0에서 명목 5 % 근처; N6에서는 측정하며 더 높을 가능성(표시 문구가 변동성 변화일 수도 있다고 말함); 5 %를 가정하지 않고 여기서 확인(#197) |

시나리오가 떨어뜨리는 것은 절차이지 전략이 아니다. 최종 시험이 기각하지 못했다고 전략이 거짓이라는 증명이 아니다. 낮은 검정력, 작은 경제적 효과, 가정 위반, 국면 변화를 따로 보고한다.

## 5. 단계

**A 단계, 지금(저장소 밖).** NumPy만 쓰는 작은 독립 스크립트를 관리자의 기계에서 돌리고, 결과에 "독립 예제이며 NexusBT가 아님"을 붙인다. 2026-11-04 검수에서 만든 두 개가 있고, 설계 세션 B가 2026-11-04에 같은 seed(20261104)와 NumPy 2.3.3으로 다시 돌려 같은 숫자를 얻었다.

- N0에서 S5(20,000회, 252일, 12번 확인, 단측 α = 0.05): 고정 종료일 4.825 %(965), 처음 유의할 때 멈춤 18.095 %(3,619), 사전 선언한 12번에 Bonferroni 2.145 %(429). 분산을 아는 IID 정규이며 Sharpe 추론도 의존적 수익도 아니다.
- N0에서 S1·S2(20,000회, z 점수): 연구 자료에서 골라 한 번 시험하면 K = 1, 10, 1,000에서 5.2 %, 4.9 %, 5.1 %; 시험 자료에서 최고를 고르면 5.2 %, 40.3 %, 100 %(정확한 가족별 오류 1 − 0.95^K = 5 %, 40.1 %, 100 %).
- 상호작용 입력(D11): x1과 x2가 각각 같은 확률로 −1 또는 +1, y = x1·x2. 두 주변 상관은 모두 0이고 곱은 y를 정확히 예측한다. 단일 IC 관문은 두 입력을 모두 버리겠지만 스펙에는 그런 관문이 없다(관문은 표시만).

**B 단계, M6 뒤(엔진).** 같은 DGP를 합성 TDS 패키지(4.8)로 만들어 `evaluate`와 `backtest(method=…)`로 돌려, 엔진의 DSR·PBO·BHY와 집단·선택 기록을 잰다. M6 통계 티켓을 끊을 때 8.3 속성 행이 된다. 이 파일은 그것을 제안할 뿐 스펙을 고치지 않는다.

## 6. 다루지 않는 것

실제 시장 자료, 엔진 자체의 오류율(B 단계는 아직 없음), 순차 절차(confidence sequence, alpha spending)와 reality-check 검정(SPA, White)은 통계 기록의 범위 결정을 기다린다. 사용성 주장도 다루지 않는다.
